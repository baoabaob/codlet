# M3 / M4 验收面板

这个消费者使用版本化 capability 和主世界回调 API，不读取 Desktop 私有对象，不拥有 CDP 或独立后端连接。依赖可选的 Desktop Adapter。

安装命令、权限和调用示例见 [开发说明](../../docs/DESKTOP_ADAPTER_DEVELOPMENT_2026-09-10.md)。在独立测试客户端安装后，右下角会出现 **M3 / M4** 按钮。

1. 在 Desktop 打开一个测试任务，点击面板中的“刷新任务”并选中它。
2. “读取回合”和“模型 / 技能 / provider”验证读接口。
3. 默认关闭测试拦截。开启后，在 Desktop 输入 `[M3]` 前缀会移除前缀并追加校验上下文；`[M3 BLOCK]` 前缀会阻止提交并显示来源。
4. 面板的“发起回合”“追加输入”“中断回合”使用相同 Desktop 连接。中断必须填写当前回合 ID。
5. 待处理审批和问答会显示在面板里；回复后等待事件确认。插件不自动允许任何审批。

测试追加的上下文包含 `M3_CONTEXT_7F2C9A`，可用“只回复追加上下文中的校验标记”检查上下文注入。事件框显示 Thread、Turn、Item 标识，不展示流式正文。

禁用或重载面板会清理自己的按钮、面板、回调和拦截器。不会删除任务历史。当前 SDK 只操作本窗口已加载的 owner 任务；新建任务和跨 host 操作不在示例范围内。
