# GitHub Release Check

两个可独立打包的发布样例：`v1` 和 `v2`。ID 均为 `dev.example.github-release-check`，仅申请 `ui.dom`。启用后右上角显示版本标记，停用或卸载后移除；不读文件、不联网、不启动 Host。

这是本地测试素材，尚未上传 GitHub。发布与导入步骤见 [M5b 发布规范](../../docs/GITHUB_PLUGIN_DISTRIBUTION.md)，界面验收见 [M5b 手测指南](../../docs/GITHUB_PLUGIN_MANUAL_TEST_2026-09-12.md)。不要把项目源代码归档当作插件构建资产。
