# Codlet Icon Assets · v1

定稿：用户选定的第一轮 B 款。保留顶部环、鱼头圆眼、C 形身体和下方编织尾环，去除字母 B 和原图背景。

## 文件

| 文件 | 用途 |
| --- | --- |
| `svg/codlet.svg` | 黑色矢量母版，用于浅色界面 |
| `svg/codlet-white.svg` | 白色矢量母版，用于深色界面 |
| `svg/codlet-currentcolor.svg` | 支持 `currentColor` 的矢量版，适合内联到组件中 |
| `png/black/` | 黑色透明 PNG，共 14 个尺寸 |
| `png/white/` | 白色透明 PNG，共 14 个尺寸 |
| `ico/codlet.ico` | Windows / favicon 黑色图标，含 8 个尺寸 |
| `ico/codlet-white.ico` | Windows / favicon 白色图标，含 8 个尺寸 |
| `preview.png` | 深浅背景及实际像素尺寸预览 |
| `source/selected-b-reference.png` | 定稿源图的裁切留档，不用于正式显示 |
| `asset-manifest.json` | 画布、颜色、尺寸及导出参数 |

PNG 尺寸：16、20、24、32、48、64、96、128、180、192、256、512、1024、2048 px。

ICO 尺寸：16、20、24、32、48、64、128、256 px，32 位 RGBA，采用 PNG 图像帧。

## 使用规范

- SVG 为真实贝塞尔路径，没有嵌入位图、字体或外部资源。
- 母版使用 `0 0 1024 1024` 画布；标志最长边为 800，最小安全留白为 112（约 10.94%）。所有 PNG 采用同一居中方式。
- 黑色为 `#000000`，白色为 `#FFFFFF`。PNG 和 ICO 的外部背景与内部留白均为透明。
- 浅色背景使用黑色版；深色背景使用白色版。不要把黑色透明图直接放到黑色界面上。
- `currentColor` 版应内联使用，才能继承父组件的 CSS `color`；用 `<img>` 加载外部 SVG 时不会继承外部页面的颜色。
- 优先使用 SVG。必须使用位图时，按目标像素尺寸选取对应 PNG，避免反复缩放小图。
- 16 / 20 / 24 px PNG 和对应 ICO 帧经过轻微描边加粗，以改善细线显示；32 px 及以上沿用母版线条。推荐常规界面至少显示为 24 px。
- 本包为无底板的单色图标。预览中的白色卡片、深色卡片与灰色底只用于展示。

## 清稿说明

从已选 B 款原图提取轮廓，去除背景后进行贝塞尔曲线矢量化，再统一留白与尺寸导出。没有重新生成或替换图标的概念结构。

已检查 PNG 的尺寸和透明通道、ICO 的全部尺寸帧、SVG 的路径结构，以及深浅背景下的视觉表现。
