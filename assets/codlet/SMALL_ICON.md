# 侧栏小尺寸图标

当前选择：侧栏暂时恢复官方 Cube 方块图标。以下小尺寸品牌图标保留为备选资产，当前 Codlet 导航入口不使用它。

`svg/codlet-small.svg` 从 B 款原始矢量直接派生，保留全部外轮廓、鳍和尾部交叠线，只删除眼睛对应的子路径。2026-09-16 按用户反馈恢复原稿形状，不再使用重新绘制的实心剪影。

沿用原始 1024 单位坐标和 currentColor，将 viewBox 调整为 `32 32 960 960`，仅缩减空白，使有效轮廓在 16 px 控件中约占 13.3 px，与原生侧栏图标接近。仅在侧栏调用 `createCodletIcon(React, {compact: true})`；页面标题等较大位置继续使用包含眼睛的 B 款原稿。

本文件与小尺寸 SVG 是后续派生资产；`asset-manifest.json` 保留原 B 款定稿导出清单。
