# 了解 Codlet

Codlet 是 Codex 桌面客户端的轻量扩展运行时。Core 管理插件注册、权限、生命周期和能力调用；可选的 Codlet 管理界面提供插件列表、导入、更新、设置和文件入口。GUI 停用后仍可使用 scoped CLI，本技能也由 Core 提供，不依赖 GUI 插件。

插件可以在界面侧运行，也可以在后台 Host 运行，或组合两者。插件通过声明的能力和依赖协作。Core 的 `context.codex` SDK 提供已适配的客户端功能，具体能力以运行时探针为准；普通插件不需要安装 UI/Desktop Adapter。

## 快速开始

1. 读 `runtime.json` 和 scoped CLI 的 `plugin list --json`，用显示名介绍用户已安装的插件
2. 按用户目标推荐下一步：使用现有插件、发现插件、导入、更新或创建。无需先询问创建插件专用的名称/目录/UI 选择
3. GUI 的“插件管理”支持全部/已启用/未启用、刷新列表、添加、详情、启停和更新；标题旁的问号介绍本技能，“试一下！”打开入门草稿，“创建插件”打开另一个创建草稿，两者均不自动发送
4. 用户也可以在任意会话输入 `/` 并从菜单选择 Codlet；技能标签代表已经选择技能。不要把单纯填入 `/codlet` 文本当成已经选中的证据

## 安装、更新和数据

- 本地插件引用用户所选的项目目录；文件变化可通过本地自动重载配置处理
- GUI 仍是独立可选插件，Core 内置原 UI/Desktop Adapter 的实现。旧同名注册、权限、源码和存储保留但不执行第二份；移除旧注册不会停用使用 Core SDK 的插件。缺少 GUI 仍可使用本技能和 CLI
- 便携版默认将 Codlet 数据放在自身 `data/`，MSI 默认使用当前用户的 Codlet 数据目录。以 `runtime.json` 与 CLI 包装脚本为准；`CODLET_HOME` 只选择 Codlet 数据，不改变官方客户端的账户或会话目录
- GitHub 插件从公开 Release 的构建 ZIP 导入，存放在默认插件目录的 `github/<插件 ID>` 下。不是下载仓库源码就能安装；没有 Release 资产或有多个候选时需选定合适的包
- “检查更新”只发现候选，“更新/全部更新”才下载并安装。仅实际 GitHub 来源或核验过的 installer update channel 可自动检查；普通本地项目不因此加入渠道，旧 Adapter 注册由 Core 替代执行后也不自动下载。官方名字不代表有可用的远端更新来源
- 安装器管理的常驻程序通过后续安装器升级。兼容在线模块包按实际二进制、桥接协议和模块 ABI 预检，不能在线生效的内容明确标记下次启动。当前本地候选未公开发布，不把未配置显示成“已是最新”
- 成功更新后只保留当前包，旧包会清理；不要承诺可从任意历史版本一键回退。更新失败时 Core 尝试恢复当前安装，实际结果以回执为准
- 设置可控制启动时检查插件更新、本地自动重载、Codlet 自动检查，并提供安装目录和错误日志入口
- 设置分别显示已编译 Core 版本、已生效 JS Core 版本、当前客户端版本和适配记录；在线回执另列生效范围与保留组件。“下次启动生效”只表示已暂存，当前任务/连接继续运行，不自动提示重启或再次安装。Codlet 检查不负责更新官方客户端；另行明确选择的官方联合更新才有独立重启流程。开发版未配置发布源时没有可查询的 Codlet 发布版本

## 安全模式与支持范围

客户端支持记录独立获取并缓存，断网时使用缓存或内置基线；“自动检查更新”关闭时不自动获取，手动检查仍可刷新。记录是特定 Core/Native/平台的验证证据，不能代替运行时能力探测，也不启用插件或修改权限。未知 Native 版本不等于全部不兼容；只限制实际不可用或无法安全核验的能力。

安全模式通过启动参数手动进入，不会因单个插件错误自动触发。它跳过外部插件和 Core 语义 providers 的激活，以及 Codlet 更新检查；保留正常客户端启动与恢复管理入口，不删除注册、授权和用户文件。这不是给受信插件增加恶意代码沙箱。先正常关闭由当前 Codlet 启动的客户端；普通 Core 使用 `codlet launch --safe-mode`，隔离测试客户端使用它原有的 `Start-TestClient.ps1 -SafeMode`。不要在测试客户端上调用另一个正式 Core，不创建独立安全模式快捷方式。正常无参数重启回到常规模式。安全模式中仅允许停用、撤权和保留源码的移除，不允许启用、重载、导入或更新。

标准 SDK 权限不继承 Core 自己的 raw Host、CDP 或 Native 私有访问。执行选定程序/Shell、full Node、main world 和 raw CDP 是可见例外；私有 DOM 是作者声明/审核，isolated world 仍共享 DOM。SDK Host 缩小 ambient API，不提供 OS 或恶意代码安全沙箱。旧注册与数据迁移不静默扩大授权。

当前目标为 Windows x64/ARM64 和 macOS Apple Silicon；macOS 仍需真机验收，不能将交叉编译等同于设备验证。Linux 暂不适配。客户端升级可能让私有接口适配失效；依据实际版本、插件错误和适配记录回答，不声称所有新版本都已支持。

内存高或启动慢不等于 Codlet 泄漏：先按 PID、启动来源和插件观察定位进程，保留用户当前工作，不按名称终止全部 Codex/ChatGPT 进程。更多步骤见 [管理与故障排查](management.md)。
