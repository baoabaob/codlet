# 0.2.0-preview.22

Codlet's runtime skill now finds the existing local Desktop connection by its
interfaces and ownership, so a new client version does not hide `/codlet` merely
because it is absent from a version table. Ambiguous or unavailable connections
remain unavailable without creating a second app-host connection.

The companion releases are UI Adapter 0.1.9 and Desktop Adapter 0.2.6. They
discover compatible native modules and interfaces on unlisted builds, support
the new route-object representation, retain the previous JSX route path, and
keep composer actions independent of page navigation. GUI 0.1.7 is unchanged.
Update both adapters as well as Core to receive the complete fix.

The Windows setup also includes the previously reviewed focus outline,
collapsible scrollbar, chevron, title, version and language refinements.

Isolated Windows acceptance passed on frontend 26.928.20755 / 12246 with
App Server 0.159.0, and on 26.924.22138 / 11645 with App Server
0.158.0-alpha.2.1. Checks cover the GUI, ordinary plugin RPC, composer clicks,
native page toolbar, unsubmitted draft creation, lease cleanup, runtime skill
and normal shutdown. The tests used synthetic onboarding and loopback API
fixtures; they did not use real account credentials or install a new MSIX.

This release supplies Windows x64 artifacts only. The native official-update
action and plaintext traffic hooks retain their separately reviewed contracts;
passing a renderer compatibility probe is not acceptance of those features.
