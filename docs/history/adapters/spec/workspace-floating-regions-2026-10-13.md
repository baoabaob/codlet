# Native body viewport and floating regions

`getSurface()` now supplies optional `bodyViewport:{rect}` and `floatingContent:[{element,rect,visible}]`. The body viewport keeps the **full vertical interval of the Native scroller**, falling back to Native content/main on other pages. It does not subtract the composer height. A consumer still clips its body to the current Native `footer.rect.top` and uses the original composer/footer coordinates for its input and target hint.

The effective horizontal region follows the current Native frame `contentX` motion and visible Native floating edge regions. Native's inspected layout moves centered body/footer by half a reserved side width, so the driver reads the live displacement rather than a fixed panel width. Gutter mode with no displacement still preserves visible floating regions at the edge. The existing Native floating nodes are not duplicated, reparented or globally restacked. A body lease excludes these nodes when suppressing replaced content.

The surface subscribes to the existing Native motion value and narrowly observes role/floating nodes' style/class/inert/aria-hidden attributes. Transform changes can move a footer without changing its ResizeObserver dimensions; they now dirty geometry and notify subscribers. These changes coalesce through the existing event/frame scheduler. There is no permanent frame loop or timer and no document-wide style observer. Retirement disconnects the extra subscriptions. The same role rectangles are reused for viewport computation instead of duplicate base layout reads.

The frozen old scene established a Native footer/composer shift after a real summary toggle. A later, separately timed DOM probe found a visible but inert/aria-hidden floating container alongside the scroller. It did not prove a `hideBody` visibility lease hid that container, and its width/position differed after user interaction. This patch fixes the missing region/geometry contract; the consumer-owned instance still needs to verify summary visibility and header/footer alignment together in a stable selected scene.

For the independent right viewport, the owned Native atom prefix is `codlet.workspace.viewport.`. The test-only [readonly namespace check](../../../../codex/tests/fixtures/workspace-acceptance/viewport-persistence-readonly.js) lists only matching key names in Native's initialized frontend atom cache. It never reads values or unrelated settings. An empty result after close proves frontend namespace removal, not a durable backend flush. The exact Native durable storage location remains unverified; do not broaden this probe to draft or other user settings.
