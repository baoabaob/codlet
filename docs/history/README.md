# Historical records

These records preserve earlier design decisions, failures, measurements and acceptance boundaries. Their versions, counts and client identities describe the original run; they do not certify the current product.

| Directory | Contents |

Current interfaces live in [spec](../README.md#sdk-contracts), current repository ownership in [repository-layout](../repository-layout.md), and versioned delivery evidence in [releases](../releases/README.md).

[document-moves.json](document-moves.json) records original repository commits, source paths and SHA-256 values for this reorganization. Markdown links were rebased to their new locations. The 0.2.0 readiness and split 0.3.0 validation archives omit their duplicated v1 introduction; original complete files remain in Git at the recorded commit. Raw historical JSON measurements were moved byte for byte. No previous Release archive or local rc.1 delivery package was replaced.
