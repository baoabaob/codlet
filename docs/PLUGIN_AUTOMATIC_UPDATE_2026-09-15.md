# 单击更新与全部更新

单个插件的“更新”与筛选栏右侧的“全部更新”调用同一个 Core 队列。Core 从当前注册记录读取 GitHub 来源，选择最高的新版本，自动匹配已安装平台对应的 ZIP，下载、校验摘要并使用现有 prepare/submit/operation 事务安装。无需用户再次选择版本或点击下载。全部更新会检查全部当前注册的 GitHub 插件（最多 128 个），本地开发目录和内置插件不属于此队列。

稳定版本不选择预发布版本；无法排序的版本、截断的发布列表或多个无法区分的 ZIP 不自动猜选。下载包必须属于同一个插件 ID，清单版本也必须实际更高。获取期间注册记录变更会拒绝旧预览。

同源更新沿用已授权限、文件/网络/进程范围与启用状态。新增权限，或依赖/所提供能力变更时，下载后标记“需要确认”，不会自动扩大授权。用户可直接打开已经准备好的审核内容。某一项失败不会重新提交其回执；已提交但长时间未完成的操作只查询原票据，队列等待其终态。

队列由 Core 持有，关闭 GUI 不取消已授权的更新。`versionStatus.pluginInstall` 提供逐项阶段、版本、错误及操作票据。每次 Core 只运行一个队列；失去启动响应时 GUI 先读取状态，不能盲目重发。客户端自己的更新仍由官方管理，Codlet 不请求其公开清单。

2026-09-16：安装目录固定为 `packages/github/<插件ID>`。下载与替换期间的资源放入内部暂存目录，旧运行实例确认退出后再替换。安装成功后清理旧包，注册记录只保留当前版本，管理界面移除历史和回退入口。安装失败仍恢复之前可用的文件和授权；短期事务日志用于处理中断，启动时不会覆盖后来发生的权限变更。
