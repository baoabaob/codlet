# 插件标签

插件在 `codlet.json` 顶层声明可选的 `tags`，例如：

```json
"tags": ["UI", "Enhancement"]
```

推荐写法为 `UI`（界面）、`Adapter`（适配层）、`Tool`（工具）、`Enhancement`（体验增强），允许作者添加自定义标签；这不是固定分类枚举。标签不放进 `i18n`，切换语言后保持原文。清单中不写 `#`，界面使用独立 SVG 显示井号。

每个插件最多 8 个标签，每个标签 1–32 个 Unicode 字符，可使用字母、数字、连字符和下划线；不允许空白、井号以及不区分大小写的重复标签。省略字段或使用空数组表示没有标签，兼容原有插件。该字段只描述插件，不影响权限、依赖或启用状态。

列表按清单顺序在版本号后显示标签，使用细描边和暖橙色圆头井号；横线保持水平，两条竖线轻微倾斜。窄窗口允许标签换行，更新按钮仍放在标签后面。

搜索框直接输入 `Adapter` 可以搜索标签及原有名称/描述；输入 `#Adapter` 只匹配这个完整标签，不区分大小写。多个搜索词取交集，也可以与已启用、未启用筛选一起使用。本地和 GitHub 来源读取同一清单字段。

点击列表中的标签会把 `#标签` 加入搜索栏，保留已有文字和标签，不重复添加同一标签。搜索栏保持焦点，可以接着输入其他条件。

在搜索词起始处输入 `#` 会出现当前已安装插件的标签候选；继续输入可按前缀缩小候选，不区分大小写。候选不受当前列表筛选结果限制，已选标签不再重复推荐。上下键选择、Enter 补全，Esc 先关闭候选，再按一次清空搜索；Tab 保留正常焦点导航。补全只替换光标所在的标签词，保留前后内容。中文输入法组词时不筛选或接受候选。关闭列表标签显示后，仍可使用标签搜索和补全。
