# 插件管理界面与更新（2026-09-13）

本轮统一了插件列表、导入、详情、确认页和验收面板的返回方式，并完成语言支持和 Codlet 自身更新。

## 界面

- 标题旁显示版本；主列表使用搜索栏、单一导入入口和刷新图标，移除重复的 Codlets 标题。
- 搜索支持 ID、名称、描述和多个关键词，兼容中英文元数据。悬停只显示描述。
- 导入页使用同一返回按钮和本地/GitHub 选项。路径输入停顿 400ms 后自动检查，旧结果不会覆盖新输入；切换语言保留表单和授权选择。
- 社区链接只放在导入页，以带下划线及外链图标的链接显示。
- 详情显示名称、描述、ID、版本、来源和实际已授予的权限；空权限范围不列 None。源目录通过文件夹图标在 Explorer 中打开，不常驻展示路径。
- 移除确认默认保留源文件及插件数据，可单独勾选删除源目录。登记或目录身份变化时不会误删替换目录；位置消失时正常注销并提示跳过删除。系统、共享注册表及运行时目录受到保护。
- 官方插件名称、描述和 GUI 文案跟随客户端实际语言：中文使用中文，其他语言先使用英文。测试插件不做翻译。

## 文件夹选择修复

在本机对同一个真实目录执行无窗口 COM 测试，原始 `\\?\` 路径使 `SHCreateItemFromParsingName` 返回 `0x80070057`。转换为普通盘符路径后，该调用及 `SetFolder` 均成功。选择器现在保留系统选项、使用专用 STA，并将默认目录作为可回退的提示。

## 更新

已先核对当前官方客户端实际代码，见 [官方流程核对](OFFICIAL_UPDATE_FLOW_2026-09-13.md)。官方 Windows 的检查通常包括下载和暂存；本轮按需求保留 Codlet 的显式“下载 → 安装并重启”交互。安装确认说明会中断当前客户端的本地任务。

Codlet 目前没有已发布更新源，显示开发版；默认不向虚构地址检查、不伪造最新版。发布步骤和更新清单格式见 [运行时更新](RUNTIME_UPDATES.md)。官方客户端的更新在 Codlet 中只作提醒。

更新包仅包含相应客户端可执行文件、Node 和其校验信息；不会替换插件目录或用户数据。安装前校验当前文件、暂存文件、启动器和进程身份，使用安装目录级互斥和明确交接；失败时根据可确认的状态恢复或保留证据。

- Rust 完整回归：539 项通过；原有真实客户端验收门禁保持忽略。
- 固定 Node 24.21.0 完整回归：189 项通过，含更新 helper 与真实 PowerShell 启动器夹具。
- 本地浏览器检查了列表、导入、详情、移除确认、中文/英文回退、深色模式及 480px 窗口；修复了样式覆盖 `hidden` 导致按钮仍可见的问题。

更新源尚未发布，因此线上更新下载没有可供验收的真实发布版本；包格式、校验、安装交接、恢复及重启通过本地包和独立夹具验证。
