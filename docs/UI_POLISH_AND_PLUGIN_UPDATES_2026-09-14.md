# UI 细节与插件更新检查

本轮根据实际测试反馈修正，继续使用 OpenAI Apps SDK UI 0.2.2 的原始组件。公开库未提供与客户端 Public / Personal 完全相同的轻量标签组件，因此保留现有 soft / ghost Button，不复制私有控件样式。

## 页面与浮层

- 标题、搜索框、筛选和插件文本共享内容左边缘，取消各处额外的 8 / 12px 内缩
- 副标题、插件描述和普通说明去除末尾句号；只处理显示，保留内部标点、省略号、版本号、源文件及错误原文
- 工具栏改为刷新、添加；添加使用官方 Menu、ChevronDown、Cube、Plus。2026-09-15 起“创建插件”已接入官方新任务编辑器，预填简短且可编辑的 Codlet 需求说明，不自动提交；“导入插件”沿用现有流程
- tooltip/menu 使用 body 下的自有浮层容器，继续同步宿主主题；页面、工具栏和浮层共享 Escape 所有权并一起卸载，避免裁切和跨窗口键盘事件泄漏
- 深色已勾选但禁用的开关不再回退为 SDK 默认蓝色，通过官方公开 token 使用减弱的宿主强调色

## 插件更新范围

原有手工流程可列出 GitHub 发布、检查下载包、确认权限并更新，保留历史回退。本轮增加默认开启的 `checkPluginUpdatesOnStartup`，由两个启动器的运行时 owner 在启动时检查一次，GUI 是否打开不影响检查。

检查只读取当前已注册 GitHub 来源的发布元数据。同一仓库只请求一次；最多检查 128 个托管插件、32 个仓库，每请求 15 秒、整次 120 秒截止。手工检查在同一检查进行时合并，结束后 60 秒内复用结果。owner 退出时取消工作。没有自动下载、运行、授信或修改注册。

按语义版本比较安装来源 tag 与新发布 tag（可有 v 前缀），选择最高的可比较版本；稳定版本不提示预发布，无 ZIP 包的发布不作为候选。非语义 tag、目录截断和网络错误分别保留 unknown / failed，不冒充最新。列表显示“新发布”，点击进入既有 GitHub 更新审阅；下载之后仍验证包内插件 ID、来源与授权。同 tag 重发、自定义版本规则需通过详情手动查看。

结果绑定当前 `versionKey`，插件移除、回退或更新后过滤旧结果。启动开关仅影响下次启动，手工检查始终可用。设置中的“检查间隔”控制 Codlet 自身更新；官方客户端兼容性检查保持独立 15 分钟。本地插件由作者更新源文件，内置插件随 Codlet 更新。

旧 schema 1 偏好文件缺少新字段时，只在读取结果中补 true，不写回文件；显式保存仍通过完整四字段、revision CAS 和原子替换。
